## Örnek Kullanım

Aşağıdaki örnek, Apache Kafka için temel yaklaşımı göstermek amacıyla sade tutulmuştur. Production ortamında validation, hata yönetimi, güvenlik, logging ve test katmanları ayrıca ele alınmalıdır.

```ts
await producer.send({
  topic: "orders.events",
  messages: [
    { key: order.id, value: JSON.stringify({ type: "OrderPaid", orderId: order.id }) }

```

## Performans ve Ölçekleme

Apache Kafka performansı ölçülürken tek bir metriğe bakmak yeterli değildir. Ortalama değerler çoğu zaman yanıltıcıdır; P95/P99 gecikme, hata oranı, kaynak tüketimi, kuyruk birikimi, cache davranışı ve kullanıcıya yansıyan deneyim birlikte değerlendirilmelidir.

Ölçekleme kararı verilmeden önce darboğaz belirlenmelidir. Sorun CPU mu, ağ mı, veri modeli mi, yanlış cache stratejisi mi, yoksa gereksiz senkron bağımlılıklar mı? Bu soruya cevap vermeden yapılan optimizasyon genellikle maliyeti artırır ama problemi çözmez.

## Güvenlik ve Bakım

Apache Kafka kullanılan sistemlerde güvenlik sonradan eklenen bir eklenti gibi düşünülmemelidir. Input validation, permission kontrolü, secret yönetimi, dependency taraması, log hijyeni ve audit ihtiyacı tasarımın parçası olmalıdır.

Bakım tarafında ise şu yaklaşım etkilidir:

- Major versiyon yükseltmeleri küçük parçalara bölünmelidir.
- Kritik bağımlılıklar için sahiplik belirlenmelidir.
- Deprecated API kullanımı CI aşamasında yakalanmalıdır.
- Incident sonrası aksiyonlar backlog’da kaybolmamalı, iyileştirme planına dönüşmelidir.
- Dokümantasyon, sadece kurulum notu değil karar nedeni de içermelidir.

## Test Stratejisi

Apache Kafka için test stratejisi, riskli davranışları güvence altına almalıdır. Her şeyi test etmek mümkün değildir; bu yüzden en kritik kullanıcı akışları, veri dönüşümleri, hata senaryoları ve entegrasyon sınırları önceliklendirilmelidir.

İyi test stratejisi şu dengeyi kurar:

- Unit test ile saf iş mantığı hızlı doğrulanır.
- Integration test ile dış bağımlılık sınırları kontrol edilir.
- E2E test ile kritik kullanıcı akışı güvenceye alınır.
- Contract test ile servisler arası beklenti kırılmaları erken yakalanır.
