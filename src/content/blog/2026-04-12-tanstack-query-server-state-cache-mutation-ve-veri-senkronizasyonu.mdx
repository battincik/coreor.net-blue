## Örnek Kullanım

Aşağıdaki örnek, TanStack Query için temel yaklaşımı göstermek amacıyla sade tutulmuştur. Production ortamında validation, hata yönetimi, güvenlik, logging ve test katmanları ayrıca ele alınmalıdır.

```tsx
const userQuery = useQuery({
  queryKey: ["users", userId],
  queryFn: () => fetchUser(userId),
  staleTime: 60_000,
});

const updateUser = useMutation({
  mutationFn: saveUser,
  onSuccess: () => queryClient.invalidateQueries({ queryKey: ["users"] }),
});
```

Bu örnek bir başlangıç noktasıdır. İyi production kodu; tip güvenliği, gözlemlenebilirlik, geri dönüş stratejisi ve hata davranışıyla birlikte düşünülmelidir.
