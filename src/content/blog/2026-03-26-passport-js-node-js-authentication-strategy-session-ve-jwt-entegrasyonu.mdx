## Örnek Kullanım

Aşağıdaki örnek, Passport.js için temel yaklaşımı göstermek amacıyla sade tutulmuştur. Production ortamında validation, hata yönetimi, güvenlik, logging ve test katmanları ayrıca ele alınmalıdır.

```ts
passport.use(new JwtStrategy(options, async (payload, done) => {
  const user = await users.findById(payload.sub);
  if (!user) return done(null, false);
  return done(null, user);
}));
```

Bu örnek bir başlangıç noktasıdır. İyi production kodu; tip güvenliği, gözlemlenebilirlik, geri dönüş stratejisi ve hata davranışıyla birlikte düşünülmelidir.
